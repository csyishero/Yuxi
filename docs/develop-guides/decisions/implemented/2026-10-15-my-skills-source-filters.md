# 我的技能来源筛选与管理入口

状态：implemented
类型：feature
Owner：web/src/components/extensions/SkillMarket.vue

## 问题

右侧“我的技能”包含本人原件和市场已安装项，而“技能管理与上传”只使用共享/个人 Skill 目录，遗漏市场安装。用户从右侧进入管理后找不到刚安装的市场技能。右侧没有来源筛选，也不能集中查看当前可用的共享和系统 Skill。

## 决策

右侧技能列表按“全部、私人、共享、系统”筛选当前用户目录。“私人”包含本人文件原件及本人市场安装，并在条目上标明真实来源；“共享”包含当前用户可用的共享 Skill；“系统”包含内置 Skill。市场安装和同源共享副本在“全部”中沿用现有来源关联规则避免重复入口。搜索作用于各来源，标题和分类计数都与当前查询结果一致。

管理抽屉列出本人市场安装并明确标为只读审核版本，提供市场详情、Agent 配置和本人卸载入口；本人原件保留现有可编辑入口。其他用户的安装不会出现在本人管理清单，也不能通过此入口删除市场发布或其他用户的数据。

## 替代方案

- 只把右侧按钮改名为“市场详情”：无法解决管理抽屉与“我的技能”数据不一致，也没有来源浏览。
- 把市场安装伪装成个人文件 Skill：会错误开放已审核版本编辑和个人文件删除。

## 后果

市场安装可能已失去当前部门可见性。本人仍能看到并卸载旧安装，但不能打开失权市场详情或读取审核内容。右侧分类中的“私人”只描述当前账号的安装关系，不改变市场发布版本的只读属性。管理抽屉的数据同时来自 Skill 目录和本人市场安装清单，刷新后才能反映服务端的最终状态。

## 验证

- 前端目录单测覆盖本人原件、本人安装、共享/系统来源、同源合并、失权旧安装和搜索后分类计数；ESLint 与 Vite 构建通过。
- 现有市场安装 HTTP/PostgreSQL 用例校验本人安装和卸载权限。浏览器自动操作受本机安全策略限制，最终页面交互仍需在当前预览中人工核对。
