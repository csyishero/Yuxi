# 文件预览手动刷新

状态：implemented
类型：feature
Owner：web/src/components/AgentFilePreview.vue

## 问题

Agent 更新文件后，用户需要在已打开的预览内主动读取最新内容，不能依赖目录轮询或关闭重开。

## 决策

对话侧栏、个人空间及其全屏预览提供刷新按钮。共享预览组件只发出刷新事件，宿主复用各自加载器和迟到响应保护。对话预览先使当前缓存失效；预览 API 读取绕过 HTTP 缓存；二进制响应生成新的对象 URL 并释放旧对象。

加载、保存或编辑期间禁用刷新；失败后保留刷新入口。刷新不修改磁盘文件。无刷新加载器的静态预览不显示按钮。

## 替代方案

- 仅刷新目录列表：不能确保已打开预览重新读取内容。
- 自动定时刷新所有预览：增加网络开销，并可能覆盖编辑草稿。

## 后果

用户可在预览右上角手动读取 Agent 最新改动。编辑草稿需要先保存或取消，再刷新。个人空间知识库来源沿用原知识库预览加载器，权限检查仍由各文件接口负责。

## 验证

回归覆盖普通与全屏按钮绑定、加载/保存/编辑禁用、三种对话侧栏文件来源重新读取、二进制对象 URL 替换、失败重试及切换文件后的迟到响应隔离。API 测试核对预览请求使用 no-store。前端生产构建验证模板装配。

浏览器操作受当前环境限制，真实交互截图尚未取得，组件与 API 回归不能替代真实页面验证。
