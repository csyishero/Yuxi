# 市场文件预览能力与错误语义

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/agents/skills/market.py

## 问题

市场详情和审核快照列出完整文件树，但在线接口只读取受支持的 UTF-8 文本。点击二进制附件会发出必然失败的请求；市场接口把“文件不存在”和“不支持预览”合成一条错误，路由将其误判为 404，页面显示“请求资源不存在”。编码不符合 UTF-8 的脚本还会抛出未归类的解码错误。

## 决策

文件树为普通文件附加 `previewable` 标记，语义与服务端文本类型判断一致。市场详情与审核快照保留全部文件，标出不可预览的附件；点击时在预览区域说明原因，不请求文本接口。脚本等受支持的文本继续按原文预览。服务端将真实缺失返回 404，不支持的类型或编码返回 400；文件读取失败在预览区域呈现。

## 替代方案

- 只列可预览文件：会隐藏发布包附件，审核员无法知道完整内容。
- 前端复制一份扩展名白名单：与服务端规则容易漂移，仍可能发出无效请求。
- 让所有文件经过文本接口：二进制内容无法可靠展示，且会扩大读取接口语义。

## 后果

旧文件树响应没有 `previewable` 时前端仍尝试读取，兼容部署中的短暂版本差异。标记按文件类型判断，不保证文本编码正确；编码异常由读取接口和页面错误状态处理。二进制附件可在审核快照完整下载包中检查，市场详情暂不提供单文件下载。

## 验证

单元测试覆盖脚本和附件的标记、非 UTF-8 脚本的受控错误以及页面不发送无效请求；真实 HTTP 测试核对脚本 200、附件与编码错误 400、真实缺失 404。
