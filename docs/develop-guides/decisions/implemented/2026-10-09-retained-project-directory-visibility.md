# 删除项目后的留存目录可见性

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/services/workspace_service.py

## 问题

未勾选文件夹清理时，项目软删除仍使个人空间过滤掉现存目录。磁盘文件保留，但页面消失造成文件误删的观感。

## 决策

个人空间使用独立的目录可见性查询，显示当前用户 active 或 deleted selectable 项目的实际目录；磁盘扫描决定目录是否仍存在。项目列表继续只显示 active 项目。本决定补充[managed 项目生命周期](./2026-10-08-managed-project-lifecycle.md)的默认保留行为。

已删除的 projects 容器根绑定不扩大目录可见性，具体项目子目录仍由对应记录决定。implicit、其他用户与未归属的匿名目录沿用已有展示边界，Workspace 的 no-follow 文件授权保持生效。

## 替代方案

- 只提示文件仍在磁盘：用户仍无法在个人空间管理留存文件。
- 展示全部 projects 子目录：会改变匿名会话目录的现有展示约定。

## 后果

删除项目并保留目录后，用户可在个人空间继续查看文件，项目不会重新出现在项目列表。显式清理后的目录按磁盘实际状态消失，无需额外目录生命周期字段。

## 验证

真实归属查询测试覆盖留存 managed/linked 目录可见，以及已删除容器根、implicit、其他用户、匿名目录不扩大可见性。真实 HTTP 测试覆盖省略清理参数与显式 false：回读项目删除状态、零清理任务、普通个人空间列表、文件内容及磁盘字节。
