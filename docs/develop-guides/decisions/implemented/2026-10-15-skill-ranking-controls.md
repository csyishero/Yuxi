# 市场热门榜的统计口径展示

状态：implemented
类型：simplification
Owner：web/src/components/extensions/SkillMarket.vue

## 问题

榜单原先把“安装榜／点赞榜”和“全公司／单部门”都做成并列分段按钮。两个选择作用于不同维度，外观却相同；市场目录旁的“按发布时间展示”说明也容易与排行榜入口混淆。

## 决策

市场目录保留“查看热门榜”入口。榜单中用标签切换安装人数和点赞人数，用标注为“统计成员”的选择框切换全公司与部门口径；超级管理员可以选具体部门，其他用户只能选本部门。榜单说明和空状态跟随当前口径变化，结果仍只包含当前用户可查看的市场技能。数据请求沿用已有排行榜 API 和统计定义。

## 替代方案

- 保留两组分段按钮并加说明文字：仍需要用户先辨认两组同形控件的职责。
- 为每种指标和范围创建单独榜单页面：入口和状态数量过多，当前需求只需两个正交选择。

## 后果

旧能力不存在：市场目录不再显示与榜单并排的发布时间说明，榜单也不再用第二组分段按钮选择统计成员。

重新引入条件：如果后续出现多个相互独立的榜单页面或跨部门对比需求，应重新评估导航结构，而不是在当前抽屉叠加一组按钮。

## 验证

- 旧能力不存在：市场目录不再显示发布时间说明，榜单没有第二组分段按钮。
- 重新引入条件：出现跨部门对比或多个独立榜单页面时，重新评估导航结构。
- 排行榜仍使用既有市场统计 API；相关前端单测、ESLint 和 Vite 构建通过。
- 浏览器自动操作受本机安全策略限制，最终视觉与键盘交互仍需在预览页面人工核对。
