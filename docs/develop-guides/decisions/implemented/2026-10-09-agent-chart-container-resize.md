# 智能体分布图按可见容器尺寸绘制

状态：implemented
类型：bug-fix
Owner：web/src/components/dashboard/AgentStatsComponent.vue

## 问题

Dashboard 系统概览使用 v-show 保留隐藏卡片。隐藏期间数据更新触发 ECharts 初始化时，容器宽度为零；恢复显示没有触发 window.resize，柱形和标签保持错误的窄画布。loading 替换卡片节点也需要重新绑定图表。

## 决策

组件等待 DOM 更新，监听数据、loading 和主题，使用 ResizeObserver 绑定实际图表容器。容器不可见或尺寸为零时等待恢复，容器尺寸变化时按当前数据重新绘制；长名称按每个分类可用宽度截断，完整名称仍可通过 tooltip 查看。空数据清空旧系列。卸载释放图表和观察器，迟到更新不再创建实例。

## 替代方案

仅监听窗口 resize 无法覆盖标签页、侧栏和卡片变化。定时器猜测布局完成时机增加等待与重试，容器尺寸事件直接表达绘制前提。

## 后果

修正局部渲染生命周期，不改变历史统计、排序、TOP 3 选择或 API。该问题具有明确复现和局部修复，不新增长期机制，因此直接记录为 implemented。
