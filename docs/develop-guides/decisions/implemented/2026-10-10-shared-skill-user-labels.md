# 指定人员共享 Skill 显示用户名

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/agents/skills/service.py

## 问题

技能卡片的人员共享范围只有用户 UID，通用标签只显示“只读用户(人数)”，无法看出共享给了谁。普通用户也不能调用管理员的人员列表接口取得名称。

## 决策

技能卡片列表只为当前用户可见的人员共享 Skill 批量查询范围内的用户名，按共享范围原顺序返回 `read_user_names`。前端在卡片上显示这些名称。权限和可见性仍由技能列表服务决定，用户名由 UserRepository 查询。

## 替代方案

- 前端调用管理员人员列表：普通用户无权调用，也会扩大数据可见面。
- 继续显示人数并要求进入配置查看：普通用户仍无法获知具体共享对象。

## 后果

当前可见的共享范围会向卡片查看者展示其中的用户名；已删除的用户显示“已删除用户”。不可见 Skill 的共享成员不会进入查询或响应。

## 验证

- HTTP 接口测试确认普通用户仅取得可见 Skill 的共享用户名，并且不可见 Skill 的成员不进入查询或响应。
- 前端 lint、build 与技能目录单测通过；本地服务更新后，网页和 API readiness 返回 200。浏览器安全检查暂不可用，页面点击验收待人工确认。
