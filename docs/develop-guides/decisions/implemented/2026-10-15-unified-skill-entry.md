# 统一技能入口

状态：implemented
类型：simplification
Owner：web/src/components/extensions/SkillMarket.vue

## 问题

“技能”和“Skill 市场”分列扩展页的顶层标签时，发现和管理技能需要跨两个入口。统一入口还需要区分本人可用的技能与待安装的市场发布条目。

## 决策

扩展页只保留“技能”顶层标签。技能页默认以全宽“我的技能”展示本人原件、本人市场安装及当前可用的共享和内置技能；顶部切换到“技能市场”后只展示当前账号可见的已上架市场条目。上传、个人技能发布、发布记录及本人安装管理从“我的技能”进入；管理员通过独立的“技能治理”视图处理更广的管理范围。页面不再并列显示右侧个人空间或独立的“管理与上传”重复清单。内部布局和交互取舍由[技能页个人首页决策](./2026-10-15-skill-personal-home.md)记录。旧 `tab=market` 链接转到统一入口。

市场审核、安装和点赞继续通过现有 API 与后端权限实现。管理员的“共享申请”和“市场审核”分别打开共享申请与市场审核申请，沿用各自的审批权限，不合并审核状态或发布副本。同一个人原件经共享和市场分别发布后的来源合并规则见[同源技能合并展示](./2026-10-15-skill-origin-dedup.md)。页面重排不迁移或重写原有技能、安装与账号数据。

作者从市场卡片查看自己的个人原件时，详情链接携带个人范围；共享和内置技能继续进入公共详情范围。详情页按范围查找同名技能。

## 替代方案

- 只改两个标签的名称：发现和管理技能仍分散在不同顶层入口。
- 把旧共享技能迁入市场：会改变自动可用、审核和版本语义。
- 继续并列显示混合目录、右侧个人空间和管理抽屉：同一技能仍会在多个清单中出现。

## 后果

用户从“扩展 → 技能”进入个人可用清单或市场发现视图。“我的技能”独立取得本人市场安装，包含失去市场可见性的旧安装，供本人卸载；同源作者原件与本人安装合并展示。共享和内置技能仍按原权限自动可用，市场技能仍需主动安装，停用的旧技能不作为可用项展示。市场只列市场发布条目，不通过来源筛选混入共享或内置技能。
