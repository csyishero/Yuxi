# 市场脚本按源码预览

状态：implemented
类型：bug-fix
Owner：web/src/components/extensions/SkillMarket.vue

## 问题

市场详情和提交快照把所有文本文件都交给 Markdown 预览器。脚本源码中的字符会被解释成 Markdown 结构，预览结果可能与文件原文不同，也让资源类提示难以与文件读取错误区分。

## 决策

`.md` 文件继续使用 Markdown 预览；其他可读取的文本文件使用保留空白和换行的纯文本代码区域。文件树、读取权限和服务端文件类型校验仍由现有接口负责。

## 替代方案

- 给全部文件使用代码编辑器：增加依赖和渲染成本，且市场发布内容只读。
- 继续按 Markdown 渲染脚本：源码中的语法可能被重排或转换，无法可靠核对审核快照。

## 后果

脚本预览不提供语法高亮，但按原文显示且不会执行脚本内容。超长行可在预览区域横向滚动。

## 验证

前端组件测试验证 `.md` 仍走 Markdown 预览，`.py` 以原始文本显示；ESLint、Vite 构建与预览部署检查覆盖页面装配。
