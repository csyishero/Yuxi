# 数据总览统一统计范围切换

状态：implemented
类型：feature
Owner：backend/package/yuxi/repositories/dashboard_repository.py

## 问题

管理员既需要审计全部历史，也需要查看当前有效对象对应的使用记录。各图表独立过滤会产生互相矛盾的数字。

## 决策

页面提供“全部历史（默认）/当前有效记录”两项切换，并贯穿系统概览、调用趋势、排行、反馈与会话明细。API 使用 scope=all/current，默认 all；current 要求会话未删除、所属项目 active、用户未注销、智能体仍存在。归档会话仍属有效记录。历史使用的事件时间与 Token 缺失口径不变。当前资源和知识库库存始终展示当前值。

统一范围在仓储查询处执行，保持超级管理员权限。切换清除旧范围结果并重新加载，旧请求不得覆盖新范围；会话筛选随范围切换重置，当前有效范围不提供已删除状态选项，后端冲突组合返回空集合。范围不改变实际数据和删除行为，不引入持久化 schema 或新的审计机制。

## 替代方案

仅在会话表提供开关无法同步图表和累计量；客户端过滤无法覆盖服务端汇总与分页。默认排除历史削弱审计，因此默认 all。

## 风险

current 表示当前有效对象的历史使用，不等于正在运行。删除和注销会改变 current 数字，all 保持历史口径。
